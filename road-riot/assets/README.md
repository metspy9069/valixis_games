# Road Riot asset credits

The 3D models in this folder are from Kenney's CC0 asset collections:

- Car, city-commercial, city-suburban, city-roads, and toy-car collections
- Source: https://kenney.nl/
- License: Creative Commons Zero (CC0 1.0)

The sound files are CC0 assets indexed by `Mcamento8/open-game-sfx-index`:

- Engine sound from Kenney's Sci-fi Sounds collection
- Natural engine idle recording from SFXMint, CC0 1.0: https://sfxmint.com/sounds/mechanical-engine-43
- Pickup, boost, and collision sounds from the Level Up / Power Up / Coin Get collection
- Source index: https://github.com/Mcamento8/open-game-sfx-index
- License: CC0 1.0

The player supercar models are local Blender exports created for this project:

- `player-ferrari.glb` (Apex GT)
- `player-lamborghini.glb` (Hyperion GTR)
- `venom.glb` (Venom Drift-R)
- `phantom.glb` (Phantom GT V8)
