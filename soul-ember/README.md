# Soul Ember — The Last Light

A 3D dark-fantasy survival roguelite for desktop and mobile browsers. Every hero, monster, guardian, weapon and menu showcase is rendered as live articulated 3D geometry.

- Eight heroes with distinct weapons, signatures, stats and three connected build branches
- Two keyboard-first smart-target skills per hero, weapon-specific cast animations and responsive velocity-based movement
- Eighteen faster monsters with individual attack scripts across three fallen sanctuaries
- Three multi-phase guardians with unique pattern rotations, transitions and readable windups
- A hidden deterministic combat director that adjusts pressure without secretly increasing damage
- Physical rarity-coded drops, post-guardian merchants and a permanent gold-funded Armory
- Automatic line-of-sight targeting, responsive movement, dodge invulnerability and wall-aware projectiles
- Ten to thirteen meaningful choices across a successful 8–12 minute expedition
- Local progression with a separate versioned save; no account is required
- Original procedural music, ambience and combat audio generated entirely in the browser
- Optional anonymous daily/weekly challenges when the backend is configured

From the repository root, run `npm run dev:soul-ember`, then open <http://127.0.0.1:8080>.

Run `npm test` for gameplay checks and `npm run build` for the production arcade output.
See [REBUILD.md](REBUILD.md) for architecture, controls, online configuration and release limits.
